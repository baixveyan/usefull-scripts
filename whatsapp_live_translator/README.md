# WhatsApp 多会话翻译侧栏

## 功能

- 使用 WhatsApp 的可见 DWM 边界零间隙停靠，侧栏始终与 WhatsApp 同高；无边框顶栏会按系统标题栏高度动态调整。
- 在 WhatsApp 聊天标题栏（头像右侧的昵称区域）识别当前联系人；规范化昵称用于复用已有缓存，头像只作辅助。
- 当前可见聊天内容变化时执行本地 OCR；按时间、方向和文字去重。
- OCR 会按相邻时间戳边界分割消息，并对 20 秒内的空格、标点、勾号及少量识别差异做模糊去重，避免同一条消息反复进入缓存；手动输入不受此限制。
- 每个聊天独立记录“对方语言”和“我的语言”，自动识别有误时可随时手动修改。
- 双方语言设置位于左侧聊天缓存栏底部，纵向排列。
- 联系人头像从 WhatsApp 当前标题栏本地裁剪并显示；带时间戳但没有可识别文字的媒体消息显示为“图片 / 视频”占位卡片。
- “跟随当前对话”开启时自动选择 WhatsApp 当前联系人并禁用手动缓存选择；关闭后可自由查看其他缓存，但 OCR 新消息仍写入实际当前联系人。
- 底部输入文字后点击“翻译并加入”，得到带一键复制按钮的译文气泡。
- 不自动发送 WhatsApp 消息，避免误发；复制译文后由用户自行粘贴发送。

## 使用

双击 `启动多会话翻译.bat`。打开桌面 WhatsApp 并切换聊天，侧栏会自动建立或切换对应缓存。

收到的消息会翻译成“我的语言”；在底部输入的文字会翻译成“对方语言”。

为了安全，消息内容只在本次运行期间保留：每次启动和正常退出都会清空消息表。联系人、头像和语言偏好继续保留。

## 打包为独立 EXE

开发电脑先执行一次：

```powershell
python -m pip install -r requirements-build.txt
```

然后双击 `双击打包EXE.bat`，成品位于 `dist\WhatsAppTranslator.exe`。

EXE 内置 Python、OCR 引擎、ONNX Runtime、OpenCV 和模型文件，目标电脑无需安装 Python。运行后会在 EXE 同目录创建 `data` 文件夹，用于保存联系人、头像和语言设置；消息在启动和退出时清空。

## 限制与隐私

- 只能记录用户实际打开并看到的文字消息；历史遗漏内容需要在 WhatsApp 中滚动显示后补录。
- WhatsApp 被其他窗口遮挡或最小化时暂停 OCR，避免读取到错误画面。
- OCR 与缓存完全在本机进行，数据库位于 `data/chats.db`。
- 原文会发送到在线翻译服务；截图和头像不会上传。
- 当前版本优先支持单聊纯文字消息。群聊、回复引用、图片和表情可能需要后续适配。
