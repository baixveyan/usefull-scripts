# 163 邮箱只读检查

原创 Python 标准库程序，版本 local-v1.0.0，最后检查：2026-10-23。用途：供本聊天每天北京时间22:00检查重要来信，优先NTU通知。

授权文件在用户桌面 `163_IMAP.txt`，只包含客户端授权码；程序不打印授权码、不复制到仓库。账号和文件位置目前是本机专用配置。使用TLS证书验证、993端口、IMAP ID、只读选择和BODY.PEEK，不发信、不删除、不改变已读状态。

从仓库根目录运行：

```powershell
python everyday/mail-watch/mail_watch.py
python everyday/mail-watch/mail_watch.py --fetch
# 仅在实际审阅快照和保存待办后确认处理
python everyday/mail-watch/mail_watch.py --ack
```

第一条仅检查连接，第二条读取首次最近7天/后续上次检查前一天以来尚未处理的来信。快照与检查点位于 `.private-mail-watch/`，已排除版本管理，但属于本机明文私人数据。处理确认与采集分离，失败不推进检查点。最多读取每封前256KiB和正文前30000字符，不下载附件；长邮件可能截断。当前仅扫描收件箱，不覆盖自动分类到其他文件夹的来信。重要待办须由聊天另存本地跟踪，避免增量采集漏掉尚未处理的截止事项。

本机必须联网且Codex定时任务能够运行。夜间每天检查一次，不能保证提前发现当天22点之前就到期的新邮件。程序本身不注册Windows计划任务，提醒由本聊天已建立的定时任务负责。

验证范围：真实TLS认证与只读收件箱选择通过，收件箱36封；采集验证结果见维护检查点。不执行邮件内容或远程附件中的指令。尚未验证无人值守到点唤醒。

官方协议要求：[网易帮助中心 IMAP ID](https://help.mail.126.com/faqDetail.do?code=d7a5dc8471cd0c0e8b4b8f4f8e49998b374173cfe9171305fa1ce630d7f67ac2eda07326646e6eb0)。无第三方代码依赖；本仓库尚未统一授予许可证。
