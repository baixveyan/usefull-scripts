# MIMIC-IV：受控访问数据集申请指引

分类：科研数据集 / 科学研究。资料检查：2026-10-19；指南固定到 **3.1**，不是对未来最新版的承诺。

## 介绍与官方地址

用于电子健康记录研究，主要按 hosp、icu 模块组织；表格以 CSV 形式导出。[PhysioNet 官方 3.1 页面](https://physionet.org/content/mimiciv/3.1/)

## 先申请，再下载

按官方页面完成账户资质审核、所需 CITI 培训并签署该项目的数据使用协议。获批后在官方 Files 页面选择所需文件。数据许可为 PhysioNet Credentialed Health Data License 1.5.0；不要使用公开镜像替代申请。

本轮未登录、未申请、未下载；受限文件清单、实际压缩体积与摘要不可见，因此不提供猜测的总容量或自动下载命令。

## 本地目录规划

建议放在仓库外：`D:\restricted-datasets\mimic-iv\3.1\raw`；清洗输出另放 `processed`，避免覆盖原包。实际磁盘预算须在获批后依据文件清单计算，包含解压、数据库导入及工作副本空间。

下载后优先核对官方提供的摘要；若未提供，将本地 SHA-256、文件大小与下载日期保存在受控目录，仅用于后续完整性复核。不要把数据、访问凭据或带患者信息的实验输出加入本仓库。
