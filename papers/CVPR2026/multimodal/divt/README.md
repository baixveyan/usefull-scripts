# A More Word-like Image Tokenization for MLLMs

核对日期：2026-10-25。以下实验均为作者报告；本地完成原文阅读与讲解自检，未复现实验。

## 一句话总结

DiVT按视觉特征相似性动态聚类patch，再用簇内注意力生成少量视觉token；它让MLLM输入更紧凑，但token仍是连续嵌入，非真正文字词表。

## 研究背景与动机

固定网格patch重复表达同一对象，也会把对象、背景混进同一token。MLP投影保留这种冗余，增加LLM序列与KV成本。作者希望语义相近patch组成一个单位，复杂图分配更多token，简单图更少。[§1–2，PDF1–3]

“像词”是组织方式比喻，不代表每个簇都必然对应一个可命名物体或无损保留所有细节。

## 方法总览

![DiVT 原创方法详图](../../../../site/figures/divt-method-v2.svg)

DiVT替换MLLM的视觉projector：先决定哪些patch共同组成一个视觉单位，再学习如何把这一组内容送给语言模型。整个过程是**编码器特征 → 选中心 → 重新分组 → 簇内注意力 → 语言空间投影**。选中心不要求物体框、分割掩码或人工指定每幅图的token数；训练projector仍依赖MLLM原有的图文监督。[PDF4–6，Algorithm1、式1–4]

## 核心创新与关键设计

### 1. 输入输出与符号：动态的是序列长度

| 量 | 形状 / 含义 |
| --- | --- |
| $X$ | $N\times D$，图像编码器产生的patch特征；一行$x_i$对应一个空间patch |
| $S$ | $N\times N$，两两余弦相似度，不是空间距离矩阵 |
| $c_1,\ldots,c_K$ | 从原patch索引中选出的中心；$K$随图像与阈值变化 |
| $\mathcal C_k$ | 最终归到第$k$个中心的patch集合 |
| $P_i$ | 与$x_i$同维的可学习位置嵌入 |
| $Q,K_{\rm attn},V$ | 分别为$K\times d_a,N\times d_a,N\times d_v$；这里下标区分key矩阵与簇数$K$ |
| $T$ | $K\times D_{\rm LM}$，最后输入LLM的连续视觉嵌入 |

这里$d_a,d_v$用于说明线性映射接口，不代表论文明确公布了独立的头数或维度配置。原文的$W^Q,W^K,W^V$采用列向量记法；表格按批量行存储说明，不能把矩阵相乘方向混用。576个patch是实验基线，不代表所有编码器、分辨率都固定576。[PDF4–6]

### 2. 先建立相似图，再按一次排序选择中心

对于非零特征：
\[
S_{ij}=\frac{x_i^\top x_j}{\|x_i\|\|x_j\|},\qquad
n_i=\sum_{j=1}^{N}\mathbf1[S_{ij}>\theta].
\]
$n_i$统计有多少patch与$i$足够相似。Algorithm1先计算所有$n_i$，再把候选索引按$n_i$降序排列。循环时取剩余列表第一项作为新中心，删除与该中心满足$S_{cj}>\theta$的所有候选，直到列表为空。**算法框中的度数与排序只计算一次；不是每删除一组后在诱导子图上重新算度。**正文的“选择最大度”要结合这份伪代码理解，不能悄悄改成另一种贪心算法。[PDF4，Algorithm1]

新中心是某个真实patch的特征，而非迭代更新的均值。这与先给定$K$的k-means不同：这里$K$是选择结果。所有后选中心与先选中心的相似度至多为$\theta$；这不是“欧氏距离至少为$\theta$”，也不能推出同簇任意两patch互相都超过阈值。

严格大于号还决定边界行为。非零向量的$S_{ii}=1$，因此$\theta<1$时选中的中心会把自己删掉，循环可以前进；若直接设$\theta=1$且完全照抄伪代码，连自己也删不掉。零范数的保护、并列度数的排序和数值容差需实现明确，正文未交代。实验阈值在这个有进展的区间内，不应把该风险说成实验已经失败。

### 3. 重新归属：选择中心不等于固定初始成员

中心选完后，对**每个原patch**重新比较全部中心：
\[
a(i)=\arg\max_{j\in\{1,\ldots,K\}}\cos(x_i,x_{c_j}),\qquad
\mathcal C_k=\{i:a(i)=k\}.
\]
第一次删除只用于阻止重复选择过近中心，不能作为最后聚合mask。例如某patch先被中心A覆盖，但后来发现它与B更相似，就应转给B。中心本身不随重分配移动；所以这是一次最近代表指派，不是多轮k-means。[PDF4，式1]

**可手算的教学例，非论文实验：**取二维单位特征，其方向角依次为$0^\circ,20^\circ,40^\circ,60^\circ$，令$\theta=0.8$。相似度是夹角余弦：相差$20^\circ$约0.940，相差$40^\circ$约0.766。含自身的度数为$(2,3,3,2)$。假定并列按原索引，先选$20^\circ$，删除$0^\circ,20^\circ,40^\circ$，再选$60^\circ$。对$40^\circ$重分配时，它到两中心同为0.940，归属必须由并列规则决定；不能虚构其必然转到某一边。这也说明仅凭相似性未必能得到唯一“语义词”。论文未指定该并列规则。

为展示**非并列**重分配，把第三个角改为$45^\circ$：度数仍是$(2,3,3,2)$，先选$20^\circ$并删除$45^\circ$；最后中心仍为$20^\circ$与$60^\circ$。$45^\circ$与两中心相似度分别约0.906、0.966，因此最终移到后者。两簇是$\{0^\circ,20^\circ\}$和$\{45^\circ,60^\circ\}$。这些角是特征空间方向，**不是图像里的位置角**。

### 4. 簇内注意力：位置先加到value输入，再做投影

按原式2：
\[
Q_k=W^Qx_{c_k},\qquad K_i=W^Kx_i,\qquad
V_i=W^V(x_i+P_i).
\]
中心作为query询问“本簇哪些patch更值得保留”，所有patch提供key和value。位置只进入value分支，使聚合内容包含空间信息；Q/K的相似打分不直接叠加位置。注意$W^V(x_i+P_i)$一般**不等于**$W^Vx_i+P_i$，尤其投影前后维度不同。这是实现时需要核对的实际运算顺序。[PDF4–5，式2]

对每个中心生成一行mask与归一化权重：
\[
M_{ki}=\begin{cases}0&i\in\mathcal C_k,\\-\infty&i\notin\mathcal C_k,\end{cases}
\quad
\alpha_{ki}=\frac{\exp(Q_k^\top K_i+M_{ki})}
{\sum_{j=1}^{N}\exp(Q_k^\top K_j+M_{kj})},
\quad
z_k=\sum_{i=1}^{N}\alpha_{ki}V_i,
\quad t_k=\operatorname{MLP}(z_k).
\]
softmax沿patch轴归一化，每行总权重为1，簇外权重为0。原式4没有显式写$1/\sqrt{d_a}$，此处忠实展开其形式；标准scaled attention常用该因子，但不能因此声称论文实际实现一定使用。多头配置、MLP隐层与激活也需附录/代码核实。[PDF5，式3–4]

继续两成员簇的教学计算：若两个logit为$\log3,0$，权重为$(0.75,0.25)$；若投影后的value为$(2,0)$与$(0,4)$，则$z=(1.5,1)$。再经MLP得到语言模型维度的一个token。这个例子只演示聚合，value和logit并非从前面的二维方向角完整训练得到，不能当作作者参数或实验输出。

最终中心按空间位置组织输入序列。特征空间相似的patch可能空间不相邻，value位置嵌入有助于表达这一点；但正文未明确空间排序的所有细节，不能擅自断言具体行优先、列优先或并列处理。

### 5. 训练、梯度与推理分开看

训练时，视觉编码器给出$X$，当前阈值决定离散中心和归属，学习到的Q/K/V映射、位置嵌入与MLP把聚合结果接入MLLM。作者替换LLaVA-1.5的projector并保持其他骨干、训练数据及设置，细节指向Appendix A。当前核读正文没有逐阶段列全冻结/更新清单，因此不能仅根据“替换projector”断言LLM全程冻结或全程更新；复现必须补核预训练与指令微调阶段。[PDF6，§4.1]

从计算图看，阈值比较、排序、argmax是离散操作，论文没有给它们定义可微松弛。固定本次分组后，语言监督可沿MLP、加权求和、softmax和线性映射回传到可训练参数；若某阶段编码器冻结，不能因此说梯度也更新了编码器。改变特征可能在下一次前向导致另一种分组，和对离散选中心本身求导是两件事。

推理时用同一学习好的聚合器，但允许改变$\theta$；只改阈值不要求重新训练。这并不把整套方法变成训练免费，也不保证与训练阈值偏离后性能完全保持。较高阈值通常形成更多细粒度token，较低阈值通常更紧凑；因为度数排序也随阈值改变，不应把趋势擅自强化为对任意图像都已证明的严格单调性质。[PDF5、7，§3.4、Table4]

### 6. 代价、替代方案与信息保留边界

显式计算$S$需要约$O(N^2D)$运算、$O(N^2)$存储；排序约$O(N\log N)$。若聚合仍实现成稠密$K\times N$打分，即使绝大多数mask为负无穷，也不会自动变成稀疏算子。LLM拿到较短视觉序列才是主要收益之一；必须把聚类、投影、padding和LLM一起计时，不能用576/63.7直接充当端到端加速倍数。

固定网格池化实现简单，但同样网格预算不适应语义复杂度；固定数量的可学习query便于batch，却不直接输出内容决定的$K$；k-means可以迭代调整中心，但需要簇数与迭代开销。DiVT选择实际patch作代表，并以一次硬分组约束学习聚合，收益与这些限制共同存在。

每个patch参与某个簇不等于信息无损。很多高维向量被压成一个向量，小字仍可能因权重太小或编码器无法区分而消失；相似patch不保证来自同一物体。原文“避免信息丢失”的表述应理解为没有显式丢弃整个patch，而非可逆压缩证明。[PDF5]

## 局限与讨论

聚类依赖已有编码器的语义质量，小字或细物体仍可能被相似背景合并。θ与编码器特征分布相关，CLIP/SigLIP/DINOv2设置不同。稀疏/变长序列在实际批处理中的padding与内核开销需测量；正文token减少不是本地延迟或显存实测。

连续token之间较低相似度本身不能证明推理因果改善，注意力可视化也不是严格解释性保证。
