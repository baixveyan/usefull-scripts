# 方法详解返工标准 v2

用户于2026-10-22要求全部返工。106篇旧稿均进入返工队列，暂停新增，逐篇重读后更新，禁止批量套模板改成完成。原 reviewed 状态仅保留原文阅读历史；method_revision 独立记录详细版状态。

每篇方法正文应让读者能够跟随一次完整计算，按论文实际结构展开，不以凑字数代替解释：

1. 明确任务、已知量、所需标注、输入输出、坐标系及使用假设。
2. 给出统一符号表和关键张量形状，走通一个具体尺寸或数值例子。示意例与论文配置分开。
3. 分模块解释输入、运算、输出、模块间连接，以及为什么需要该模块；区分公共基础与本文增量。
4. 核心公式逐项定义，说明从何而来、如何计算、梯度或优化方向、适用条件及失败边界；必要基础推导明确标为阅读补充。
5. 分开讲训练与推理，标清冻结/更新、监督、损失权重、采样、时间顺序；适合时提供概念伪代码，不冒充作者实现。
6. 用一个贯穿例子或消融说明设计解决的具体问题，讨论复杂度与替代方案。
7. 动态分支、适应机制、特殊mask等不可省成一句；原文没有交代的实现细节写为未交代，不补猜。
8. 对照原文页码、图、公式核对。原图可放大，中文说明需解释箭头和中间表示；截图不能代替讲解。
9. 自检清单为读者能否解释输出如何由输入得到，而非仅检查章节是否齐全。公式排版问题单列，避免用质疑段落替代方法教学。

每次至多5篇。完成后更新 method-revision.json 与 manifest.method_revision，保存修订日期和原PDF哈希，检查索引与网站，再续做下一篇。所有106篇完成前不得恢复新增论文。
