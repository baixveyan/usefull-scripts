# Adapting a Pre-trained Single-Cell Foundation Model to Spatial Gene Expression Generation from Histology Images

核对日期：2026-10-22。实验数值均为作者报告；本地完成原文阅读与讲解自检，未复现实验。

方法与配图详细版返工：2026-10-23。重读§3–4与式1–5，展开mask轨迹、SoftAdaLN、冻结梯度与课程采样；未复现。

## 一句话总结

HINGE冻结单细胞基础模型CellFM，通过视觉条件调制和逐基因掩码生成，把病理图像转成空间表达预测；相关性改善不表示能够从图像完整恢复真实转录组或替代测序。（PDF第1–5页）

## 研究背景与动机

同样的组织形态可对应不同细胞组成和表达状态，病理到基因表达不是唯一确定映射。现有生成方法较少直接利用单细胞基础模型中的基因关联，但单细胞模型又缺乏视觉输入，且掩码预训练与全维高斯去噪不匹配。HINGE同时处理条件接口和输入目标匹配，主实验只实例化CellFM，并未实证覆盖所有单细胞基础模型。（PDF第1–3页）

## 方法总览

### 任务是生成spot表达，不是从照片读取单细胞真实测序

HINGE的训练样本是组织学图像patch \(c\)与对应空间spot的表达向量\(x\in\mathbb R^G\)成对出现的数据；希望学习条件分布\(p(X\mid C=c)\)。空间spot可以混合多个细胞，因此不能将一个输出向量直接称为这个patch内某个细胞的真实转录组。图像形态也不唯一决定表达状态，生成结果是统计预测，不等于从像素中无损还原实验测量。（§3.1，PDF第3页）

关键资源是一套预训练单细胞基础模型CellFM：它从表达数据学习基因关联，却没有组织图像接口。作者**冻结CellFM和病理视觉编码器**，训练较轻量的条件调制路径，将图像及生成时间步接入原Transformer。另一个关键选择是掩码生成：保留部分真实表达、遮住其他维度，训练恢复被遮住的位置，使任务接近CellFM原来的masked autoencoding，而不是改为对全部基因加高斯噪声。（§3，PDF第3–5页）

### 数据对象与模型接口

| 符号 | 形状/意义 | 容易混淆的边界 |
|---|---|---|
| \(x_0\) | \(G\)维干净表达，实验使用log尺度 | 不是原始测序read数 |
| \(m_t\) | \(G\)维二值可见性，1为可见 | 真零表达与mask不同 |
| \(x_t=m_t\odot x_0\) | 部分可见表达 | 数值占位零不能替代显式mask |
| \(\hat x_0=f_\theta(x_t,t,\phi(c))\) | 对完整表达的预测 | 损失与更新只选择特定维度 |
| \(\phi(c)\) | 冻结视觉模型的特征 | 不直接改写CellFM预训练权重 |
| \(c_t\in\mathbb R^D\) | 图像与时间的共享条件向量 | 在每个子层有不同调制映射 |

基因在进入网络前需要匹配CellFM的基因词表。论文先取与24,078个基因的词表交集，再在训练切片上做HMHVG筛选；不能因为基础词表有24,078项，就声称所有实验均准确预测了24,078个基因。HMHVG筛选、基因顺序和缺失基因处理是数据协议的一部分。（§4.1，PDF第6页）

## 核心创新与关键设计

### 正向掩码过程：单条轨迹只能丢失信息，不能自行恢复

初始\(m_0=\mathbf1\)，采用累计可见率

\[
\bar\alpha_t=\left(1-\frac tT\right)^\zeta,\qquad\zeta>0.
\]

这里\(t=0\)时全可见，\(t=T\)时全遮挡。每步从尚可见的基因中以\(p_t=1-\bar\alpha_t/\bar\alpha_{t-1}\)概率继续遮住；已被遮住的基因保持遮住。因此一条正向轨迹的mask集合具有包含关系。不同基因的掩码采样按作者设定相互独立，但表达基因之间并不因此被假设生物学独立。（§3.2、式1，PDF第4页）

训练不必逐步模拟整条轨迹。给定一个时间步，可以直接采样

\[
m_t^{(g)}\sim\operatorname{Bernoulli}(\bar\alpha_t),\qquad
x_t=m_t\odot x_0.
\]

这给出正确的单时刻边缘分布，却不表示把不同时间的独立边缘mask拼起来就是合法的单调轨迹。例如在\(t=1\)遮住基因A、\(t=2\)又让A出现，符合分别采样的可能结果，却不符合逐步正向转移。训练采样边缘与推理维护轨迹要分开理解。

### 反向恢复概率为何是这个分式

反向生成从\(m_T=0,x_T=0\)出发。若某基因在\(t\)已经可见，则在\(t-1\)继续可见；若仍遮住，则以

\[
\pi_t=\frac{\bar\alpha_{t-1}-\bar\alpha_t}{1-\bar\alpha_t}
\]

概率恢复。分子是这一反向步新增可见的边缘质量，分母是当前还遮挡的质量，因此是**在当前遮挡条件下**的恢复概率，不是所有基因一律以同一个无条件比例重新抽样。（§3.2，PDF第4–5页）

独立教学核查：取\(T=4,\zeta=1\)，累计可见率为\(1,.75,.5,.25,0\)。反向\(4\to3\)时\(\pi_4=.25\)，\(3\to2\)时\(\pi_3=1/3\)，\(2\to1\)时\(\pi_2=.5\)，\(1\to0\)时\(\pi_1=1\)。第二步后的期望可见率为\(.25+.75\times1/3=.5\)，与日程一致；最后一步保证剩下的基因全部恢复。这四步只是检验公式，**不是论文实际采样预算**。

即使每个基因的mask抽样独立，生成出的表达仍可相关：同一网络读取所有已可见基因及同一个组织图像，并利用预训练的基因依赖。不能把mask独立误读成输出的联合分布是逐基因独立高斯。

### 校准与更新：已经恢复的值会固定下来

当前模型先给出完整预测\(\hat x_0\)，然后进行可见性校准：

\[
\tilde x_0=m_t\odot x_t+(1-m_t)\odot\hat x_0,
\qquad x_{t-1}=m_{t-1}\odot\tilde x_0.
\]

这意味着已可见位置沿用\(x_t\)中的旧值；新增可见位置填当前预测；仍未恢复的位置继续遮住。（§3.2，PDF第4–5页）

例如当前mask为\((1,0,0)\)、输入数值为\((2,0,0)\)，网络预测\((9,3,4)\)，新mask为\((1,0,1)\)，则校准后为\((2,3,4)\)，下一状态是\((2,0,4)\)。第一项不会被新预测9覆盖。数值为教学构造，不是基因表达测量。

该设计保证轨迹一致，但也意味着早恢复的预测值不能在后续每步任意改写。生成中较早的误差可能成为后来条件。反向过程中的“可见”包括模型自己刚生成的值，**不是每次新揭开一份真实测序结果**；研究报告的相关性不能被理解成推理期间逐步获取真值。

### 为什么真实零表达不能等同于mask token

模型编码时，可见表达走value embedding，遮挡位置走专门mask token ID，再加入对应gene-ID embedding，形成\(G\times D\)的token序列。因此两个数值同样为0的位置，只要一个可见、一个被mask，它们的输入语义就不同。（§3.3，PDF第5页）

论文公式为了简洁把输入写成\(f_\theta(x_t,t,\phi(c))\)，实际实现仍需要可见性信息或等价token标识。只把masked entry数值置零、丢弃\(m_t\)并用“数值是否为零”判断缺失，会错把真实零表达当作未知。随机填值消融也不能说明真实表达数值不重要：它说明**被mask的位置**通过专门ID编码后，其数值占位符可以不参与编码。

### 训练目标只看遮挡维度，且使用时间权重

原式2为

\[
\mathcal L(\theta)=\mathbb E\left[
w_t\left\|(1-m_t)\odot\big(f_\theta(x_t,t,\phi(c))-x_0\big)\right\|_2^2
\right],\qquad w_t=\pi_t.
\]

网络预测完整向量，但可见维度不计入这一重建误差。否则模型可能主要学习复制当前已知值，而减少对真正缺失基因的学习压力。注意原式是范数平方，不直接写成“除以缺失基因数后的MSE”；实现是否另有归一化须核对，不能在讲解中悄悄更换目标。（§3.2，PDF第4页）

常规阶段从\(1,\ldots,T\)均匀抽取时间步；给定\(t\)再采样mask与输入。网络优化变量\(\theta\)仅包含调制参数，而不是所有CellFM权重。训练需要配对表达真值，推理则不需要待预测spot的真实表达。

### SoftAdaLN：先轻柔改变子层输入，再门控子层输出

冻结的Transformer子层为MHA和SGLU。每个子层前插入SoftAdaLN，不能简单画成“在最终输出处拼一个图像向量”。先将图像特征和时间嵌入组合：

\[
c_t=\phi_{\rm cond}([\phi(c);e_t])\in\mathbb R^D.
\]

\(\phi_{\rm cond}\)在层间共享且可训练；不同子层各自有缩放、偏移和门控映射。对某个基因token的输入\(h\in\mathbb R^D\)，原式3–4为

\[
\operatorname{SoftNorm}(h)=(1-\eta)h+
\eta\frac{h-\mu(h)}{\sigma(h)+\epsilon},
\]
\[
h'=\operatorname{SoftNorm}(h)\odot(1+s(c_t))+\kappa(c_t).
\]

均值和标准差在**该token的D个隐藏维度**上计算，不能改成整张切片所有spot的批统计。\(\eta\)决定对原预训练表示做多强的标准化；正文只说它可学习，没有明确给出限制其必须始终在\([0,1]\)的参数化，因而不把它严格称为永远成立的凸组合。

以忽略\(\epsilon\)的教学小例子，\(h=(1,3)\)按总体标准差归一为\((-1,1)\)，当\(\eta=.25\)时得到\((.5,2.5)\)。它保留部分原始幅度，不等同于完全归一化；真实隐藏向量维度和分布并不是这个例子。

冻结子层计算\(u=F_{\rm frozen}(h')\)，再按原式5合并残差：

\[
h_{\rm out}=\operatorname{LN}_{\rm frozen}
\left(\tau(c_t)\odot u+\lambda h\right).
\]

\(\tau\)由线性层加sigmoid产生；\(\lambda\)继承CellFM残差缩放。这里门控作用于**子层输出**，不是给表达向量直接乘一个组织分数。decoder前还有相似的无门控SoftAdaLN，decoder本身仍冻结。（§3.3，PDF第5页）

### 恒等初始化究竟保持了什么

作者初始化\(\eta=0,s=0,\kappa=0\)，使\(h'=h\)；门控权重为零、偏置为较大正值，使\(\tau\approx1\)。因此最初接近原CellFM的子层和残差行为，而不是将子层输出清零。注意**近1门控与常见AdaLN-Zero的零门控不是同一个初始化**。（§3.3，PDF第5页）

训练只更新\(\eta,\phi_{\rm cond},s,\kappa,\tau\)相关参数；视觉编码器、CellFM、原LayerNorm及decoder冻结。冻结权重仍允许梯度经过其算子传给调制器，不能对整段冻结网络不加区别地切断计算图，否则调制器可能收不到正确梯度。

最初近似原行为不意味着训练后的条件函数完全不变。改变各层输入统计、门控和条件偏移可以改变基因依赖的实际输出。预训练知识较好保留是作者动机和实验观察，**不是仅凭参数冻结即可推出的生物学关系严格不变定理**。

### Warm-start改的是抽哪些时间步，不是重写可见率日程

CellFM预训练约遮住20%的基因。HINGE初期仅抽低遮挡时间步，即\(\bar\alpha_t\ge1-\rho\)、\(\rho\approx.2\)，让新调制路径先适应接近原预训练分布的输入。之后恢复在全时间范围均匀抽样。（§3.4，PDF第5页）

\(\bar\alpha_t\)曲线本身不因训练阶段改变；同一个\(t\)在早期与后期对应相同掩码水平。若选\(\zeta=1\)作教学，则初期时间带满足\(t/T\le.2\)。不要将它说成“推理时先从20%mask开始”，因为正式生成仍从100%mask出发；也不要把训练迭代数与反向mask时间步混用。

### 生成多样性从哪里来，证据还缺什么

在固定网络与图像条件下，反向过程通过重采样mask恢复轨迹产生不同样本；不是从标准高斯表达噪声开始。不同恢复顺序会使后来预测读取不同的已生成基因值，这提供多样性来源。正文没有把该多样性证明为校准后的测量噪声或真实条件不确定性。

一个边界例子是\(T=1\)：全mask状态下预测一次，最后全部恢复；若网络无额外推理随机性，mask轨迹也无选择自由，不能据“这是生成模型”就保证重复输出多样。此例仅检查机制边界，不评价作者实际多步配置。

复现还需从附录/代码核实\(T,\zeta\)、warm-start长度、优化器与学习率、视觉特征组合、多样本数和聚合方法、跳步采样的转移概率。生成均值、单次样本和多样本均值可能有不同误差，不能把它们混在同一张比较表。此次未下载数据或模型，以上推演均为独立代数与接口自检，不是本地转录组生成结果。


## 实验与关键结果

数据为cSCC12切片/4患者、Her2ST36切片/8人、Kidney23切片/22人；采用留一切片测试，其余训练中留10%早停。**留切片不等于留患者**，同一人其他切片可能参与训练。基因与CellFM24,078词表取交集，再按训练切片均值和方差选HMHVG；表达及误差处于log尺度。（PDF第6页）

| 表1作者报告 | HINGE PCC-50↑ | PCC-200↑ | 参考基线PCC-200 |
|---|---:|---:|---:|
| cSCC | 0.705±0.006 | 0.613±0.008 | STFlow 0.578±0.012 |
| Her2ST | 0.566±0.008 | 0.446±0.010 | Stem 0.433±0.019 |
| Kidney | 0.428±0.009 | 0.309±0.010 | TRIPLEX 0.299±0.025 |

跨测试切片与三随机种子统计。Kidney的MSE1.459、MAE0.964，高于TRIPLEX1.315/0.915，因而不是全部指标最优。基因共表达矩阵及marker图是结构性补充，不能证明基因调控因果关系。（PDF第6–7页）

## 消融实验与证据强度

表2–5主要在**单个cSCC P2_ST_rep3切片**开展，不能与全数据均值混用。PCC-200随机训练0.6395、仅调decoder0.7699、骨干LoRA0.7618，HINGE0.8021。高斯扩散0.6415，掩码无课程0.7932，完整0.8021，支持匹配预训练目标的价值。（PDF第8页）

去SoftNorm为0.7874，去恒等初始化0.7722；UNI单编码器0.7871，CONCH0.7783，联合0.8021。各消融说明所选配置互补，尚不足以证明每个新患者都同幅受益。随机填掩码与填零几乎相同，是专门掩码token生效的合理结果，而非所有输入缺失都无关紧要。

## 局限与讨论

相同组织图像不能识别全部潜在表达状态，生成样本的不确定性是否校准也未由PCC验证。留切片协议、候选基因选择和预训练数据重叠需要进一步审计；其他单细胞骨干兼容性是架构论述，不是多骨干实验。正文缺少足以复现全部学习率、时间步和采样预算的细节，相关分析在附录。本文仅作方法阅读，不据此给出医疗诊断建议。（PDF第3–8页）
