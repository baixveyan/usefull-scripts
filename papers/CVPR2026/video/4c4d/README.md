# 4C4D: 4 Camera 4D Gaussian Splatting

作者：Junsheng Zhou, Zhifan Yang, Liang Han, Wenyuan Zhang, Kanle Shi, Shenkun Xu, Yu-Shen Liu。

分类：video；交付形式：Markdown 中文论文讲解。

核对日期：2026-10-20。以下实验均为作者报告；本地完成原文阅读与讲解自检，未复现实验。

## 一句话总结

4C4D用可学习透明度衰减与时空可见性分流，缓解四相机动态高斯重建中外观容易拟合、几何却不稳定的问题。

## 研究背景与动机

稀疏视角无法充分约束动态几何，模型能在训练视角拟合颜色却在新视角产生漂浮伪影。作者把优化重点放在透明度调节，而非仅扩大外观表达或假设需要几十台相机（第1–3页）。

## 方法总览

以带时间均值、时长与四维协方差的高斯表示动态场景。轻量网络读高斯位置、透明度、旋转，预测衰减系数；当前视图及时刻可见的高斯用神经衰减，不可见部分用常数0.999；与图像渲染损失联合优化（第3–5页）。

## 核心创新与关键设计

o(t)=τ·exp[−(t−μ_t)²/(2Σ_44)]·o，其中τ=fθ(x,y,z,o,r)用于可见高斯，其余τ=β。时间条件均值通过协方差交叉项控制运动。可见性由中心视野和时间跨度筛选，是渲染可贡献性的近似，不能直接等同完整遮挡推理。梯度更关注几何是作者优化解释，不是几何唯一恢复证明。

## 实验与关键结果

第5–7页公共数据选四个训练相机、其余相机测试，前300帧。Neural3DV PSNR22.29/LPIPS0.146，对4DGS20.60/0.244；ENeRF24.32/0.121对23.52/0.151；Mobile-Stage22.36/0.121对22.15/0.180。DSSIM两个版本data range为1和2不能混用。自采Dyn4Cam四GoPro风格相机、1080p60FPS，无额外测试机位，仅定性结果。

## 消融实验与证据强度

第8页代表场景表4：无神经衰减22.60、无可见性24.49、完整24.68dB；此处不是Neural3DV全数据均值22.29。表5常数衰减24.31、幂24.35、指数24.32、神经24.68，支持学习式折中，但未证明所有衰减函数的全局最优。正文对无神经项称固定衰减，而表5同数值标None，复现需核对。

## 局限与讨论

四台相机仍需同步和几何标定，视场覆盖不足会保留不可见歧义。PSNR/LPIPS衡量渲染，不直接证明毫米级动态几何。自采无held-out视角，不能报告其新视角GT分数；未报告足以验证普通手机实时训练的证据。

## 复现提示

记录选定相机ID、标定同步、首300帧、分辨率、初始化及衰减生效时序。需核查神经衰减值域、透明度更新实现和训练硬件/耗时，正文未完整披露则查补充及代码。本地未运行，项目4C4D页的代码版本与许可证未确认。

## 相关工作与阅读顺序

先分清4DGaussians的形变场和4DGS的原生时空高斯，再看Ex4DGS与稀疏视角正则。此处4D包含时间，与Ga4DPF的四维特征提升含义不同。
