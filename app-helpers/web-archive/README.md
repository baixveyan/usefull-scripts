# SingleFile：把网页保存为一个 HTML 文件

适合保存教程、活动说明、资料页面和稍后阅读内容。分类：软件辅助 / 导出。资料核对：2026-10-19；未安装扩展、未捕获真实网页。

## 获取与开始

从[作者仓库](https://github.com/gildas-lormeau/SingleFile)的 Install 区域进入对应浏览器商店，核对发布者与扩展标识；不要从同名搬运站下载。作者提供 Chrome、Firefox、Edge 等入口，Safari 使用对应平台扩展。

打开想保存的页面，先展开需要保留的内容、等待图片加载，再点击工具栏 SingleFile 按钮。默认保存位置使用浏览器下载目录；建议把资料归档到 `D:\archives\web\年份\主题`，不要放进本源码仓库。

## 推荐验收方法

1. 先用不含个人信息的公开页面测试。
2. 保存后断网打开 HTML，检查正文、图片、中文、链接及样式。
3. 在归档文件旁记录原 URL、保存时间、扩展版本和页面标题。
4. 动态图表、视频、交互控件和需要登录的资源逐项验证，不能把“单文件”理解为整站和所有交互都完整保留。

## 隐私与分发

作者提供[隐私说明](https://github.com/gildas-lormeau/SingleFile/blob/main/privacy.md)，实际行为还取决于所启用的保存目标和设置。初次使用只选本地保存，不启用云端上传。登录后页面的归档可能包含你的个人信息；分享前人工检查。

源码上游标示 AGPL-3.0，部分第三方组件另有许可。这里仅提供指南，不复制扩展代码。安装版本、权限变化及完整许可以实际包为准；本轮未取得固定 commit，也未验证商店安装流程。商店页面可访问不代表扩展在你的浏览器已可用。
